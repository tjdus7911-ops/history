# Figma Rev.4 구현 매핑

기준 파일: `iL6dHoA2qFaggZjqNub77u`  
기준 페이지: 이름이 `Rev.4`로 시작하는 12개 페이지  
실제 제품 화면 프레임: 84개 (Home 2 + Story 28 + Exam 21 + OX 5 + Wrong 14 + Records 4 + Common 10)

빈 `Page 30`은 제품 화면 수에서 제외했다. Cover, IA, Foundations, Component Library, Prototype 페이지는 화면 수가 아니라 구현 규칙과 흐름을 확인하는 문서로 사용했다. Prototype 페이지의 4개 흐름은 기존 라우팅과 아래 런타임 테스트로 검증한다.

## 공통 구현

- `dist/rev4.css`: Rev.4 컬러, 의미 토큰, 타이포그래피, 8pt 간격, 반경, 버튼 높이, 390px 모바일, 430px 최대 폭, safe area, 44px 최소 터치 영역을 정의한다.
- `dist/rev4-ui.js`: 공통 아이콘, 버튼, 배지, 빈 상태, 5탭 내비게이션, 첫 방문/학습 중 홈, 통합 검색, 오답 필터 시트, 오답 상세, 토스트, 오프라인 배너와 스토리 후처리를 제공한다.
- 기존 스토리·기출·OX·오답·기록 런타임과 저장 스키마는 그대로 사용한다. 콘텐츠 데이터 파일은 변경하지 않는다.
- Component Library의 49개 최상위 컴포넌트 패밀리 중 시스템 상태 바/홈 인디케이터는 브라우저 safe area에 위임하고, 나머지는 공통 클래스 또는 기존 런타임 컴포넌트에 Rev.4 토큰을 적용한다.

| 컴포넌트 그룹 | 코드 매핑 |
| --- | --- |
| Button, Icon Button, Badge, Era Tag | `.rev4-button`, `.rev4-icon`, `.rev4-badge`, 기존 시대 태그 |
| Filter Chip, Tab, Segment, Progress, Timer | `.tabs`, `.ed-tabs`, `.official-*tabs`, `.progress`, 시험 타이머 |
| Bottom/Top Navigation, Section Header, List Row, Search Field | `.rev4-navigation`, `.rev4-home-header`, `.rev4-section-title`, `.rev4-search` |
| Story Header/Stat Strip/Bubble/Character/Choice/Action | `.rev4-immersive` 아래 공통 스토리 규칙 |
| Learning Summary, Discovery, Era/Chapter/Scene/Continue Card | 기존 스토리 런타임 카드 + Rev.4 토큰 |
| Exam/Question/Answer/Question Cell/OX Answer | 기존 기출·OX 런타임 + Rev.4 상태 스타일 |
| Result/Weakness/Choice Explanation/Explanation | 기존 결과·분석·해설 런타임 + Rev.4 상태 스타일 |

| Empty/Loading/Error/Inline Banner | `.rev4-empty`, 기존 해설 로딩·오류, 오프라인 배너, 저장 실패 토스트 |
