# CH.05–12 구현 및 검수 보고서

## 작업 전 기준선

- 최신 `main` 기준 CH.01–04 활성 장면은 101개, 구조화 대사는 502줄로 챕터당 평균 25.25장면 / 125.5대사였다.
- CH.05–12는 메타데이터만 있고 `implemented:false`, 장면·문제·완료 흐름이 없었다.
- 후기 고려에 대응하는 검증 완료 공식 문항은 기존 문제 은행에 없었다. 출처를 확인하지 못한 문항을 실제 기출로 표시하지 않는 원칙을 유지했다.
- 935년 도윤은 전신 구도, 주인공은 상반신 구도라 동일한 CSS 높이에서 도윤의 얼굴과 몸이 훨씬 작게 보였다. 이미지 여백보다 원본 구도 차이가 원인이었다.

## 학습 리듬

각 학습 블록은 다음 구조로 연결된다.

1. 사건을 장면에서 먼저 경험한다.
2. 동행 인물 또는 역사 인물의 반응으로 판단 단서를 얻는다.
3. 필요한 경우 플레이어가 태도를 선택한다. 선택은 역사적 결과를 바꾸지 않는다.
4. 3문항을 끊지 않고 연속으로 푼다.
5. 각 답변 뒤 역사 해설과 게임 속 기억을 확인한다.
6. 3문항 세트 점수를 본 뒤 다음 이야기로 복귀한다.

CH.12의 마지막 문제 세트는 조선 건국 장면 직후에 끝난다. 이후 `918년 장터 회상 → 늙어 간 사람들 → 고려 474년 → 조선 예고` 감정선에는 문제가 끼어들지 않는다.

## 역사 범위 점검

- 대외 관계: 거란 1·2·3차 침입, 여진 정벌, 몽골 침입, 삼별초, 원 간섭, 반원 개혁
- 정치: 문벌 귀족, 이자겸의 난, 묘청의 서경 천도 운동, 무신 정권, 최씨 정권, 공민왕 개혁, 위화도 회군, 조선 건국
- 사회: 음서·공음전, 특수 행정 구역과 망이·망소이, 만적, 권문세족의 토지·노비 확대, 신진 사대부
- 불교: 의천의 교장·천태종, 지눌의 수선사 결사·정혜쌍수·돈오점수, 초조대장경, 팔만대장경
- 문화: 고려청자 상감 기법, 금속 활자와 직지, 삼국사기, 삼국유사, 제왕운기
- 경제: 곡식·포 중심 유통과 화폐, 관청 수공업·소, 대농장, 과전법

- 저장 버전을 15로 올리고 기존 저장을 보존한다.
