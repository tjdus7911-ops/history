# NPC·기출 배치·자유 진입·재플레이 수정 검증 (2026-10-11)

## 판정
NPC 복구, 구현 챕터 자유 진입, 표시 중인 챕터 기준 다음 이동, 실행별 기출 큐 처리를 구현했다. 기출 정책 전체 충족은 **미완료**다. 부족분을 중복/무관 문항으로 채우거나 씬을 합치지 않았다.

| 시대 | 검사 씬 | 기본 배치 문항 | 2~3문항 충족 씬 | 부족 씬 | 최소 부족 문항 |
|---|---:|---:|---:|---:|---:|
| 원삼국 |83|23|8|75|147|
| 삼국 |215|98|23|192|340|
| 고려 |211|71|17|194|356|
| 합계 |509|192|48|461|843|

삼국 프롤로그 3씬은 시험 배치에서 제외했다. 고려의 시험 전용 노드는 스토리 씬 집계에서 제외했으며 일반 대화/내레이션 씬은 포함했다. 모든 씬별 수량·문항 ID·부족분은 `placement-audit.json`에 있다. 공식 ID와 회차/기본·심화/문항번호 두 기준 모두 기본 배치 중복 0건. 기존 라이브러리, 오답노트, 과거 풀이 기록은 삭제하지 않았다.

## 기출 출처 및 미검증 범위
- 기존 검토 자료를 재사용한 문항 113개. 이번 변경에서 모두 원본과 재대조한 것은 아니다.
- 기존 메타데이터·원본 연결만 유지한 고려 문항 67개: 공식 답안 및 모든 보기 해설의 전수 재검증은 미완료다. 각 문항의 `verification`에 구분했다.
- 제60회 기본 공식 문제지·정답표를 화면으로 대조한 신규 문항 14개. 그중 해당 씬에 맞고 3문항 상한을 넘지 않는 12개를 실제 큐에 연결했다. 2번은 관련 씬이 이미 3문항이며, 14번은 해당 문화재를 배우는 씬이 없어 미배치했다.
- 신규 14문항의 4개 보기 전체 해설, 원본 PDF/정답 PDF/이미지 SHA256, 페이지·크롭 영역을 `supplement-60-basic.json`에 기록했다. 생성기는 이미지 해시와 정답 범위, 보기 수를 검사한다.
- 잘못된 기존 해설 3건(77회 심화 11번, 69회 기본 12번, 69회 심화 15번)을 원문과 역사 자료를 확인하여 정정했다.
- 족보 원본 전체 → 실제 학습 대사 → 실제 문항의 전수 대조는 아직 끝나지 않았다. `learningConceptIds`는 기존 학습 항목이며 족보 반영률을 뜻하지 않는다. 연결 대사 증거가 있어도 원본 족보 전체 반영 완료로 계산하지 않는다.
- 미배치 후보 32건과 사유는 배치 원본에 보존했다. 기존 질문/일정 ID는 진행 중인 저장 복구와 선택 복습을 위해 유지했다.

## NPC
초상 미등록 때문에 대사 전용으로 빠진 152개 씬별 인물 ID에 독립된 얼굴을 제작·연결했다. 신규 27개 PNG(26시트+장교 단독), 기존 주인공/주요 인물 원본 유지. 신규 인물은 표정별 추가 변형 없이 동일 초상으로 표시한다.
전체 NPC 발화 1,302건과 기록책 246건의 실제 `characterStage()` 출력을 검사했다. 최초 누락 641개 발화의 씬·이름·원인은 `../three-content/support-npc-before.json`, 최종 결과는 `support-npc-audit.json`에 있다.

| 씬 | 인물 | 원인 / 수정 |
|---|---|---|
|THR-C02-S03|장교|미등록 초상 → 단독 초상 연결|
|THR-C03-S03|율령 담당관|미등록 초상 → 고유 시트 셀 연결|
|THR-C18-S07|나래의 조카|미등록 초상 → 어린이 고유 초상 연결|
|THR-C23-S07|장수 연락관|미등록 초상 → 고유 시트 셀 연결|

발화 NPC가 연출용 왼쪽 인물에 밀려나지 않도록 했으며 주인공은 오른쪽, 상대는 왼쪽에 둔다. 비발화 상대는 흐리게 남기고 기록책·화면 밖 목소리를 일반 NPC로 강제 표시하지 않는다. 모바일 390px에서 장교/담당관/조카, PC 1363px에서 조카를 실제 렌더링으로 확인했다. 모든 인물을 브라우저에서 수동 촬영한 것은 아니며 전수 검사는 렌더러 자동 검사다.

## 자유 진입 / 재플레이
66개 구현 챕터를 초기 상태에서 진입하는 자동 검사를 통과했다. 입장 권한만 열며 완료·정답·선택 기록을 만들지 않는다. 준비 중 시대는 비활성이다.
네 시대의 실제 이벤트 처리기로 첫 플레이 → 완료 → 재플레이(기출 다시 출제) → 다음 챕터 → 저장 재부팅 → 같은 대사 위치 복구를 검사했다.
- 원삼국 CH.02 → CH.03: 7문항
- 삼국 CH.03 → CH.04: 9문항
- 고려 CH.09 → CH.10: 13문항
- 조선 CH.12 → CH.13: 4문항

다음 챕터는 결과에 표시된 ID 및 같은 시대 순서로 계산한다. 별도로 저장된 메인 진행은 보존하며 마지막 챕터에는 시대 선택을 표시한다. 브라우저에서는 0% 새 사용자 상태의 삼국 메뉴에서 CH.18을 직접 선택·시작했다.

- 삼국 218씬 A/B 두 선택 경로, 98개 기본 기출, 정답/오답, 추가 복습 및 저장 복원 통과.
- 원삼국/삼국 v3 저장 회귀, 삼국 학습 경계 검사 통과.
- 원삼국/삼국 대본·시험·그림 생성 결과 검증 통과.
- 정적 PWA 빌드 검사 통과. 로컬 Windows의 Node 자식 프로세스 실행은 EPERM으로 차단되어 Python 생성 검사와 Node 정적 빌드 단계를 분리 실행했다. 배포 서버의 실제 빌드 결과는 커밋 상태로 별도 확인한다.
- 브라우저 390px/PC에서 선택·반응·합류 → 64회 심화 3번 → 60회 기본 3번 → 다음 씬을 확인. 2/2 문항에서 새로고침한 뒤 같은 2/2로 복구되어 앞 문항을 반복하지 않았다.
- 전체 기존 npm test 묶음의 모든 레거시 테스트를 실행한 것은 아니다. 이번 변경 관련 검사와 위 명시 경로를 실행했다.

## 보존 범위
기존 시대 대본/선택지/프롤로그/엔딩/문제 원본 이미지/족보 참고 파일을 삭제하지 않았다. 암기카드 118개의 문장은 그대로이며 변경된 기출 연결에 따라 카드 C004의 relatedSceneIds만 동기화했다. 기존 학습 기록이나 저장 키를 일괄 초기화하지 않았다. 이전 제목 정리와 족보 원본 사진 레이어 제거 변경은 유지했다.
