# CH.05 감정 연결 및 연 일러스트 수정

기준 main: `3630c2179fb1d62fa9112e5135df2b23c71d5835`.

## 변경

- CH.04의 도윤 작별·죽음·유산 장면을 확인한 뒤 `ch05_prologue`를 CH.05 시작점으로 추가했다. 도윤을 잊지 못하고 새 인연을 피하는 독백 5단락과 993년 전환을 하나의 내레이션 읽기 화면으로 묶었다. 인물·환영은 표시하지 않는다.
- 연과 첫 만남에서 주인공은 동행을 거절한다. 철수 후 짐 운반을 돕고, 강동 6주 마을에서는 먼저 동행을 청한다. 기존 역사 설명·장면 연결·선택 효과·문제는 유지하며 관계 관련 발화만 조정했다.
- 연의 기본/미소/걱정/진지함/놀람 5개 일러스트를 동일 얼굴·헤어·복장·자세로 제작했다. CH.05 전용 portrait override만 교체했다. 주인공·도윤·현우와 CH.06 이후 캐릭터 매핑은 유지했다.
- 빈 상단의 해 질 무렵 전용 배경 1개를 추가했다. 기존 배경 파일과 이전 연 파일은 보존했다.
- CH.05는 13장면, 실제 기출 3문제, 심화 연습 9문제다. 이전 12문제의 내용·정답·출처·이미지는 변경하지 않았다.

## 이미지 제작

`imagegen` 스킬의 기본 내장 도구를 사용했다. 참조: `player_goryeo_neutral.png`, `doyun_neutral.png`, 이전 연 이미지(정체성 참고), `ch03-doyun-courtyard.png`(건축 참고).

기본 프롬프트: 주인공·도윤과 동일한 섬세한 2D 선 처리, 단순화된 눈·코·입, 부드러운 절제된 채색, 사진 같은 피부/3D/광택 배제. 연은 넓은 얼굴, 갈색 머리띠, 청록색 옷과 녹슨 붉은 허리띠, 여행 가방으로 구별한다. 표정 편집 프롬프트는 얼굴 표정만 바꾸고 인물·자세·의상을 고정했다. 배경은 모든 인물을 제거한 쓸쓸한 고려 상단의 빈 마당이다.

최종 에셋은 `dist/assets/characters/ch05-yeon-{neutral,smile,worried,serious,surprised}-v2.webp` 및 `dist/assets/scenes/ch05-empty-guild-dusk.webp`이다. 각각 768×1152, 인물 RGBA. 이미지 후처리는 리사이즈와 WebP 저장만 수행했다. 6개 총 1,114,504바이트(약 1.06 MiB).
