## 현재 상태

첨부 확정 MD와 XLSX를 보관하고, 전체 대본·프롤로그·대사 선택·기출 배치를 실제 서비스 진입점 `dist/index.html`에 연결했다. 대사와 선택지는 원문을 보존하며, 다른 시대의 데이터와 저장을 유지한다. 생성 결과를 다음 빌드에서 다시 검사할 수 있도록 변환 원본과 스크립트도 함께 포함한다.

**콘텐츠·진행 상태의 자동 검증과 실제 브라우저 화면 검증을 구분한다.** Node VM에서 실제 진입점의 스크립트와 이벤트 처리기를 실행한 전체 A/B 플레이, 저장·기출 검증은 실행했다. 이번 환경에서는 Chromium 실행 파일을 확보하지 못했고 관리형 미리보기도 권한 오류로 시작되지 않았다. 따라서 실제 데스크톱·모바일 조작과 화면 배치를 검증 완료로 표시하지 않는다. 독립 초상이 없는 인물과 아직 세밀하게 표현되지 않은 연출도 아래에 명시한다.

## 2. 실제 게임 흐름

`dist/index.html`과 호환 미리보기 진입점 `dist/three-preview.html`은 같은 새 원본·변환 데이터·런타임을 사용한다. 과거 삼국 검토본의 30챕터·90씬 강제 검사, 심화 전용 설치 조건, 씬마다 같은 문항을 복제하는 구조는 활성 삼국 경로에서 제거했다. 원삼국 진입점과 데이터는 별도로 유지한다.

삼국편 새 게임은 `THR-PRO-S01`에서 시작한다. 첫 대사는 “한 장만 더 보고 자자.”이며, 글자 출력 중 첫 탭은 현재 문장을 완성하고 다음 탭은 다음 발화로 이동한다. 프롤로그에는 선택지나 기출을 넣지 않았다. 둘째 씬의 마지막 발화를 넘길 때만 120ms 암전 클래스를 적용한다. 셋째 씬과 본편 첫 씬은 같은 배급 줄 배경을 쓴다. 원본 족보 사진 3장은 책의 별도 이미지 레이어로 연결했다.

본편의 각 선택 장면은 다음 단계를 저장하며 진행한다.

1. 본선 대사를 끝까지 읽는다.
2. A/B 대사 버튼을 표시한다.
3. 선택한 문장 자체를 서아의 발화로 한 번 재생한다.
4. 선택한 분기의 반응과 후속 발화만 재생한다.
5. 공통 연결로 합류한다.
6. 배치표의 기록책 보충 발화가 필요하면 탭으로 읽는다.
7. 그 위치의 첫출제 큐를 순서대로 푼다.
8. 다음 씬 또는 챕터 완료 화면으로 이동한다.

선택지의 지식 점수·호감도 변경값은 비어 있다. 선택 버튼의 입력 전파를 차단해 같은 클릭으로 다음 발화까지 넘어가지 않게 한다. 긴 대사는 원문을 줄이지 않고 현재 발화 영역에서 줄바꿈하며, 선택지는 문장 전체를 표시한다.

원고 순서와 원래 연도 문자열을 유지한다. 기록 공간에 해당하는 19개 씬·244개 발화에 기록책 표시를 연결하고, 현장으로 돌아오는 9개 전환을 구분했다. CH23의 현장과 후대 기록도 이 방식으로 분리한다. 기록 목소리를 현장 NPC 초상으로 표시하지 않는다.

## 3. 기출 설치·개방·해설

`officialQuestionId`로 선정된 91문항을 각각 한 번만 설치한다. 엑셀의 1부터 시작하는 정답을 가져오는 경계에서 한 번만 0 기반 인덱스로 변환하고, 기존 공식 카탈로그·원문 검토 증거와 대조한다. 보기 수, 선택 상태와 채점은 같은 인덱스 기준을 쓴다.

기본 31문항은 4개, 심화 60문항은 5개의 번호 버튼을 제공한다. 실제 질문·자료·보기는 원본 문제 이미지로 표시하고 확대 기능을 연결했다. 모든 보기의 텍스트 전사가 있는 것은 아니므로 일부 전사문으로 문제 이미지를 대체하지 않았다. 91개 이미지의 경로·문항 식별 정보·검토 해시를 검사하며, 원문·정답·이미지 검증 플래그만 바꾸어 설치를 통과시키지 않는다.

대표 연결 215건 자체가 즉시 출제를 뜻하지 않는다. 실제 출제표의 후행 씬, 마지막 발화, 선행 학습 조건을 기준으로 개방한다. 77개 첫출제만 기본 진행에 강제하며, 22개 대표 복습과 추가 후보는 배치 조건을 읽은 뒤 기록책에서 선택한다. 문항을 열기만 한 상태와 답안을 제출한 상태를 구분한다. 동일 공식 문항을 먼저 풀었다면 이후 첫출제 큐에서 제외하고, 사용자가 선택한 복습은 다시 허용한다.

| 검증 사례 | 반영한 조건 |
|---|---|
| 64회 심화 3번 | CH01 S06의 지정 공통 대사 이후 |
| 77회 심화 6번 | 기벌포 학습을 마치는 CH13 S12 이후 |
| 73회 기본 9번 | 발해 멸망 자료를 읽은 CH22 S07 이후 |
| 79회 심화 9번 | CH23 S05에서는 해당 시점 해설, CH23 S10을 읽은 뒤 공산·사심관·일리천 상세 해설 |

기존 공부·오답·이야기 회상 경로도 삼국의 개방 상태를 확인한다. 삼국 학습 맥락에서는 공식 카탈로그의 같은 문항 별칭으로 들어가도 79회 심화 9번의 미래 해설이 먼저 노출되지 않는다. 다른 시대에서 선택한 독립 시험의 원래 해설과 진행 데이터는 보존한다.

## 4. 이어하기와 시대별 저장

새 삼국편은 `lived-history-three-kingdoms-v3` 저장 키와 `three-kingdoms-v3` 진행 키를 사용한다. 콘텐츠 버전은 `three-complete-23-v1`이다. 본선·선택·분기·공통 연결·기록책 보충·기출 단계, 현재 대사 커서, 선택지, 입력한 답안, 큐 위치와 완료한 공식 문항 ID를 저장한다.

기록책에서 복습을 시작할 때 현재 씬·분기·커서를 별도로 보관하고, 복습 중 새로고침을 해도 끝난 후 정확한 위치로 돌아간다. 기출 또는 보충 발화 큐가 진행 중이면 다른 복습을 중첩해서 시작하지 않는다. 읽은 씬·열린 문제·암기 문구·선택 기록은 누적 보관한다.

이전 삼국 검토본 저장은 보관하고 새 씬에 억지로 대응시키지 않는다. 새 콘텐츠를 자동 완료 처리하지 않는다. 삼국에 한정한 안내와 프롤로그 재시작 기능을 제공하며, 원삼국·고려·조선의 저장을 지우지 않는다.

전체 회귀 검사의 실제 출력은 [npm test 실행 기록](verification-npm-test.log)에 보관했다. 마지막 암전 수정은 전체 A/B 순회 검사 뒤 별도의 집중 검사와 빌드로 검증했다. 위 Node VM 검사에서 실제 앱 스크립트와 이벤트 처리기를 실행하지만, DOM 배치와 브라우저 입력 장치까지 실행한 것은 아니다.

실제 화면 검증을 위해 시도한 경로:

- Playwright는 설치된 런타임에 있었으나 Chromium 실행 파일이 없었다. Chromium과 headless shell 설치 요청은 브라우저 ZIP 대신 195바이트의 `SiteUnavailable` HTML을 받아 실패했다.
- 클라우드 브라우저에서 로컬 HTTP 페이지를 여는 요청은 완료되지 않아 중단했다. 화면을 본 것으로 처리하지 않았다.
- `sites-preview start`는 `bwrap: Can't mount proc on /newroot/proc: Operation not permitted`로 서버가 시작되지 않았고, 상태 조회에서도 중지로 확인됐다. 관리형 실행 환경의 보호 설정을 변경하지 않았다.
- 실제 진입점 대상 `tests/three-complete-ui-test.cjs`를 작성하고 `npm run test:three:ui`를 실행했다. Chromium 실행 파일이 없어 종료 코드 1로 실패했다. [원본 오류 로그](verification-browser-attempt.log)와 [검증 결과](verification-results.json)에 남겼다. 테스트 코드에는 390px/1280px 화면, 프롤로그 수동 진행, 3장 족보 이미지, 한 번의 암전, 대사 선택과 분기 새로고침, 아틀라스 렌더링, 4지·5지 원문 문제 검사를 준비했다. 이 검사는 아직 통과한 검사가 아니다.

미확인: 실제 픽셀 배치, 초상 크기·크롭, 모바일 가로 넘침, 긴 대사·선택지의 버튼 가림, 실제 첫 탭과 타이핑, 120ms 암전의 눈으로 확인한 길이, 원문 확대 조작과 실제 새로고침. 자동 검사 통과를 이 항목의 통과로 대체하지 않는다.

## 7. 자산과 실제 화면 검증의 제한

기존 승인된 서아의 표정 11개와 현대 모습, 호환되는 일러스트 배경을 사용한다. 218개 씬에 22개 배경을 연결했고, 프롤로그와 본편 첫 장면을 잇는 배급 줄 그림을 새로 추가했다. 그림 속 어머니는 아직 서 있는 상태이며, 프롤로그에서 구조나 급수를 마친 것으로 그리지 않았다.

반복 등장하는 생활 인물 21명의 29개 모습을 2개 투명 아틀라스로 추가했다. 나이가 달라지는 8쌍을 분리하고, 동일 인물 정체성과 동명이인을 구분했다. 이 초상은 중립 표정의 상반신 그림이며 전신 애니메이션은 아니다. 실제 자르는 영역을 각각 지정했으며, 서아는 오른쪽·상대는 왼쪽에 배치한다. 배경 인물 또는 초상이 없는 인물은 원문 화자와 대사로 등장하며, 다른 사람의 얼굴이나 회색 자리 표시자를 대신 넣지 않는다.

남아 있는 제한:

- 역사 인물 20개 모습과 단일 씬의 이름 있는 생활 인물 41개 모습에는 독립 초상이 없다. 아래 목록 및 [전체 자산 감사](art-import-audit.json)에 씬을 기록했다.
- 배경은 모든 원고의 물건·동작·군중 구성을 개별적으로 그린 그림이 아니다. 기록책·현장 구분, 연도·장소, 대사와 인물 연결은 구현했지만 세부 소품·단체 배치·모든 행동의 시각적 재현은 완성으로 표시하지 않는다.
- 새 아틀라스의 원본 그림과 나이 구분은 이미지 파일에서 검토했으나, CSS로 자른 결과의 실제 브라우저 배치와 모바일 화면은 미확인이다.
- 기출 이미지는 원문과 검토 해시를 확인했으며 확대 UI를 구현했지만, 모바일에서 읽는 크기와 버튼 가림 여부는 실제 브라우저 검증이 남아 있다.
- 브라우저 실행이 가능한 환경에서 `npm run test:three:ui`와 기존 `npm run test:mobile`을 실행하고, 프롤로그 암전·타이핑 첫 탭·긴 선택지·기출 확대·새로고침·다른 시대 복귀를 직접 확인해야 한다.

## 8. 재생성 및 후속 검토

```bash
npm run import:three
npm run check:three
npm test
npm run build
npm run test:three:ui
```

`import:three`는 이 저장소에 보관한 입력과 자산 연결에서 생성 파일을 만든다. `check:three`와 `build`는 생성 결과가 원본과 달라지면 실패하며, 이전 90씬 검토본을 다시 생성하지 않는다. 변환에 별도 Python 패키지는 필요하지 않다. 브라우저 검사는 별도로 Playwright와 Chromium이 필요하다.

이 보고서는 코드에 포함된 구현·검증 기록이다. 원격 브랜치·커밋·PR의 실제 생성 결과는 GitHub 기록과 작업 최종 보고를 기준으로 확인한다. 공유 `main` 병합과 공개 배포는 이 구현 보고의 완료 항목에 포함하지 않는다.
