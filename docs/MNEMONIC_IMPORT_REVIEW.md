# 암기법 자료 정제 검토표

첨부된 두문자 자료는 웹페이지 복사 원문으로 취급하고, 광고·URL·페이지 표기·메뉴 문구를 앱 데이터에 넣지 않았다. 역사 사실은 기존 Story와 공식 기출 DB를 우선 대조했으며, 공개 카드는 원문 표현을 그대로 복제하지 않고 학습 단위와 1~2문장 설명으로 재작성했다.

## 검토 상태

원자료 후보는 `dist/mnemonic-data.js`의 `MNEMONIC_IMPORT_CARDS`에 보관하고, 검토를 마친 16개 카드만 기존 4개 카드와 함께 `PUBLISHED`로 표시했다. 기존 15개 후보는 `ASSOCIATION_MEMORY_CANDIDATES`에 유지해 추가 검토 대상으로 남겼다. `relatedOfficialQuestionIds`는 화면 실행 시 canonical 공식 기출 DB의 문제·사건·개념 키워드로 연결되며, 문제를 복제하지 않는다.

원자료에서 제거한 노이즈 유형은 사이트명, URL, 날짜·시간, `P6/22` 형식 페이지 표기, 메뉴/구독/공유 문구, 광고 문구(PitchBook·Dola), 깨진 특수문자다. 동일 주제의 반복 항목은 하나의 학습 카드로 통합했다. ‘신해통공’을 천주교 박해로 묶는 등 사실과 맞지 않는 연결은 공개 카드에 채택하지 않았다.

카드 상세는 기존 단계별 accordion을 사용하며 기본 닫힘 상태를 유지한다. Recall Test에서는 mnemonic과 cue를 제출 전 숨기고, 정답 제출 뒤 전체 순서와 설명을 보여준다. 기존 `associationMemoryStatus` 저장 키와 카드 ID는 유지한다.
