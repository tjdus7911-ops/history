# 암기법 자료 재검토표

이번 데이터는 첨부된 RAW 원문과 41장의 화면 캡처를 다시 읽고, 역사 개념의 제목이 아니라 실제로 외우기 위해 만든 문장·두문자·리듬을 `mnemonic` 필드로 추출해 구성했다. `dist/mnemonic-data.js`의 신규 공개 카드 59개는 모두 mnemonic phrase와 cue→fact 매핑을 가진다. 기존 네 장의 암기 카드도 ID와 학습 상태를 유지하면서 mnemonic 필드를 보강했다.

## 검토 수치

| 항목 | 수량 | 기준 |
|---|---:|---|
| RAW 분절 블록 | 103 | 원문의 P 페이지 표기 기준으로 분절한 단위 |
| mnemonic 패턴 확인 블록 | 89 | 암기 문구와 대응 항목이 함께 있는 단위 |
| 앱 데이터화 대상 | 69 | 공개 59 + 기존 보존 4 + 추가 검토 10 |
| PUBLISHED | 63 | 신규 59 + 기존 보존 4 |
| CANDIDATE | 8 | 표현 적절성·매핑 추가 검토 필요 |
| REVIEW_REQUIRED | 2 | 후보 데이터에만 보존, 공개 목록에는 미노출 |
| 단순 개념 목록으로 공개한 카드 | 0 | mnemonic 없는 카드는 생성하지 않음 |
| 웹 노이즈 제거 블록 | 14 | URL·광고·메뉴·페이지 표기·구독 문구 등 |
| 중복 제거 | 0 | 같은 mnemonic을 별도 카드로 중복 공개하지 않음 |

89개 패턴 블록 중 69개를 데이터화했고, 59개를 공개하고 10개를 CANDIDATE/REVIEW_REQUIRED로 보류했다. 나머지는 원문 매핑이 불완전하거나 페이지·광고 노이즈가 섞여 있어 공개 카드로 만들지 않았다. 보류 표현을 개념 요약으로 바꾸거나 공개 카드로 위장하지 않았다.

## 공개 카드의 표시 규칙

- 목록 카드의 큰 제목은 원문의 mnemonic phrase다.
- 각 카드에는 `memoryType`(ACROSTIC/SENTENCE/WORDPLAY/SEQUENCE/NUMBER/STORY), `category`, `originalMnemonic`, `publicMnemonic`, `moderationStatus`를 저장한다.
- 상세 화면은 `암기 문구 → 외울 내용 → cue와 사실의 연결` 순서로 표시한다.
- 단계 행은 `복 → 경복궁`처럼 cue와 fact를 함께 보여준다.
- 설명은 펼쳤을 때만 보이며, mnemonic 자체는 처음부터 숨기지 않는다.
- Recall Test 제출 전에는 정답 fact를 숨기고, 제출 후 원문 mnemonic과 전체 매핑을 다시 보여준다.
- 기존 `associationMemoryStatus` 키, legacy 카드 ID, 공식 기출 canonical 연결은 유지한다.

## 시대별 공개 카드 수

| 시대 | 신규 공개 카드 | 화면 공개 카드(기존 포함) |
|---|---:|---:|
| 선사·고대 | 25 | 26 |
| 고려 | 8 | 8 |
| 조선 | 13 | 16 |
| 개항기·대한제국 | 6 | 6 |
| 일제강점기 | 5 | 5 |
| 대한민국 | 2 | 2 |

신규 59개와 기존 보존 4개를 합친 화면 공개 수는 63개이며, 시대 필터는 실제 카드의 `era` 값을 사용한다. 신규 카드 기준 유형 수는 두문자 8, 문장연상 6, 말장난 20, 순서연상 12, 숫자연상 13이다.

문구가 어색하거나 문장처럼 보이지 않아도 원문에서 기억 장치로 기능하는 경우에는 보존했다. 반대로 `광종의 왕권 강화`처럼 개념과 항목만 나열한 데이터는 신규 공개 카드에서 제거했다.
