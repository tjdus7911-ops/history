# Character Voice Guide

CH.03 이후를 포함한 모든 스토리 대사는 아래 화자 규칙을 따른다. 한 장면 안에서도 캐릭터의 시대·배경이 말투로 구분되어야 한다.

## 주인공

- 2026년 현대 한국인. 짧고 자연스러운 현대 한국어를 사용한다.
- `뭐야?`, `잠깐만.`, `진짜?`, `그건 좀 위험하지 않아?`, `됐어. 내가 할게.`처럼 말한다.
- 고려 인물에게 익숙해진 뒤에는 이름을 직접 부를 수 있다: `도윤아.`
- `~하오`, `~게`, `~소서` 같은 사극 어미를 사용하지 않는다.
- 속마음은 현대식 반말이며 `thought` 데이터로 보존한다. 화면에서는 일반 내레이션과 같은 UI로 표시하고, 별도의 속마음 카드나 라벨을 붙이지 않는다.
- CH.01에서 도윤에게 하는 말은 현대식 존댓말이다. 함께 아홉 해를 겪은 뒤에도 CH.01에서는 이를 유지한다.
- CH.02의 `ch01_jump_935`에서 함께 겪은 일을 돌아보고 말을 놓기로 합의한 뒤 현대식 반말을 사용할 수 있다. 그 전까지는 존댓말이다.
- 고려의 낯선 인물과 어른에게는 챕터와 관계없이 현대식 존댓말을 사용한다.
- `chapter-split.js`의 `PLAYER_SPEECH_POLICY`와 장면 `playerSpeechStyle`을 참고한다. 내레이션 묶음은 `readingMode: 'narration-blocks'`로 선언한다. 원래 문장과 커서 인덱스를 유지하여 기존 저장·착의 시점·문제 큐를 보존한다.
- 유행어나 인터넷 표현을 반복하지 않는다. 현대 표현은 시대 차이를 드러낼 필요가 있을 때만 쓴다.

## 도윤

- 고려 시대의 생활 상인. 읽기 쉬운 사극 말투와 장터의 거친 생활감을 함께 유지한다.
- 기본 어미는 `~하오`, `~이오`, `~겠소`, `~게요`를 사용한다.
- 주인공을 주로 `자네`라고 부른다.
- `하옵니다`, `통촉하여 주시옵소서` 같은 궁중 사극체는 사용하지 않는다.
- 현대식 반말인 `했어`, `할 거야`, `뭘 그렇게 떨어`를 사용하지 않는다.

예시:

- `무슨 말이오?`
- `잠깐 기다리시오.`
- `그건 위험하지 않겠소?`
- `내가 하겠소.`

## 현우

- 고려 시대 사람이며 공부한 과거 응시자다. 도윤보다 정돈되고 차분하다.
- 기본 어미는 `~하오`, `~겠소`, `~인 듯하오`, `~합니다`를 문맥에 맞게 사용한다.
- 감정이 커져도 현대식 반말로 급격히 바뀌지 않는다.

예시:

- `그리 단순한 문제는 아니오.`
- `나라의 법이 바로 서야 하지 않겠소.`
- `내 생각에는 다른 방법이 있을 듯하오.`

## 시대 차이를 활용하는 방법

현대 표현을 고려 인물이 이해하지 못하는 장면은 한 챕터에 한두 번만 사용한다.

> 주인공: `진짜 그 얘기로 평생 놀릴 거야?`
>
> 도윤: `진짜?`
>
> 주인공: `아…… 정말로 그럴 거냐고.`
>
> 도윤: `그럼 처음부터 정말이라고 하면 될 것을.`

개그가 장면의 감정이나 역사 학습을 방해하면 사용하지 않는다.

## 노화 복선 속도

- CH.01~03에서는 주인공이 늙지 않는다는 직접 대사·독백·MYSTERY UI를 사용하지 않는다.
- CH.03에서 필요하면 `어디서 뵌 적이 있는 것 같은데` 수준의 오인만 허용하며 주인공은 의미를 부여하지 않는다.
- CH.04~05 이후 도윤과 현우의 외형에 시간 경과를 먼저 보여 준다.
- 주인공이 자신의 상태를 명확히 인식하는 시점은 더 뒤의 챕터에서 별도로 결정한다.

## 작성 전 점검

1. 주인공 대사에 사극 어미가 섞이지 않았는가?
2. 도윤 대사가 현대 친구의 반말처럼 들리지 않는가?
3. 현우가 도윤보다 정돈된 문장을 쓰는가?
4. 현대 표현 오해 장면이 반복 개그가 되지 않았는가?
5. CH.03 이전에 노화 사실을 직접 언급하지 않았는가?
