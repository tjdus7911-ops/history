# OX 퀴즈 검수 원고

이 디렉터리의 시대별 JSON 7개가 OX 퀴즈 810문항의 문제·정답·해설 원본이다. 런타임은 더 이상 역사 용어와 임의의 오답 분류명을 조합하거나, 문제의 사실 문장을 해설로 복사하지 않는다. `scripts/build-ox-quiz-curation.cjs`는 사람이 검수한 이 원고를 검증한 뒤 `dist/ox-quiz-curation.js`로 직렬화할 뿐이다.

## 편집 계약

- 문항 ID와 시대별 개수는 기존 학습 기록·오답노트·이어하기와 호환되도록 고정한다.
- `statement`는 하나의 판단 대상을 가진 완결된 사실 진술문으로 작성한다. 질문형, 화살표 답안, 핵심 개념 분류형 문장은 허용하지 않는다.
- `answer`는 기존 배열에서 복사하지 않고 새 문장의 실제 참·거짓을 다시 판단해 기록하며, 런타임도 이 검수값을 정답 원본으로 사용한다. 이번 원고는 재판정 결과가 기존 저장 답안 키와 모두 호환되는지 별도 이행 보고서로 검사하므로 과거 풀이 결과가 뒤집히지 않는다.
- `explanation`은 정답 라벨을 제외한 2~4문장의 학습 해설이다. O 문항에는 판단 근거와 관련 맥락을, X 문항에는 틀린 부분과 올바른 사실을 넣는다.
- 문제 전체를 되풀이하거나 모든 문항에 같은 결론 문구를 붙이는 해설은 허용하지 않는다.

## 검증 자료와 범위

기본 연결 근거는 저장소의 제57~79회 한국사능력검정시험 심화 1,150문항 원문·정답·해설 목록이다. 기존 핵심 문항 210개는 공식 기출 연결을 유지하고, 확장 문항 600개는 기출 해설의 인물·사건·제도 토큰과 시대 범위를 대조한다. 연도, 인물-저술, 제도 시행 주체처럼 오답 가능성이 큰 항목은 다음 공공 역사 자료를 우선해 교차 확인한다.

- 국사편찬위원회 [우리역사넷](https://contents.history.go.kr/)
- 국사편찬위원회 [한국사데이터베이스](https://db.history.go.kr/)
- 한국학중앙연구원 [한국민족문화대백과사전](https://encykorea.aks.ac.kr/)
- 국가기록원 [국가기록포털](https://www.archives.go.kr/)
- 국사편찬위원회 [한국사능력검정시험](https://www.historyexam.go.kr/)

## 재생성 및 검사

```text
npm run build:ox
npm run check:ox
node tests/ox-quiz-test.cjs
node tests/ox-quiz-mobile-test.cjs
```

검사기는 810개 ID의 완전성, 시대별 수량, O/X 키 호환성, 진술형 문장, 2~4문장 해설, X 문항의 오류 지적, 기계적 금지 문구, 중복 문항·해설, 문제에 없던 추가 학습 정보의 존재를 확인한다. 원고 하나라도 빠지거나 생성 결과가 오래되면 빌드가 실패한다.
