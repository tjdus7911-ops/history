# OX 퀴즈 검수 원고

이 디렉터리의 시대별 JSON 7개가 실제 서비스에 노출되는 OX 문제·정답·해설 원본이다. 문항 수나 시대별 할당량, O/X 비율은 목표값으로 고정하지 않는다. `scripts/build-ox-quiz-curation.cjs`는 사람이 검수해 유지하기로 한 문항만 검증한 뒤 `dist/ox-quiz-curation.js`로 직렬화한다.

## 편집 계약

- 기존 문항의 뜻과 정답을 유지할 때만 ID를 유지한다. 제외한 ID는 `id-history.json`에 영구 폐기 상태로 남기고 재사용하지 않으며, 뜻이나 정답을 바꾼 문항은 반드시 새 ID를 발급한다.
- 시대별 개수와 전체 개수는 족보 핵심 내용의 범위에 따라 달라질 수 있다.
- `statement`는 하나의 판단 대상을 가진 완결된 사실 진술문으로 작성한다. 질문형, 화살표 답안, 핵심 개념 분류형 문장은 허용하지 않는다.
- `answer`는 문장의 실제 참·거짓을 검증해 기록하며, 런타임도 이 검수값을 정답 원본으로 사용한다.
- `explanation`은 정답 라벨을 제외한 2~4문장의 학습 해설이다. O 문항에는 판단 근거와 관련 맥락을, X 문항에는 틀린 부분과 올바른 사실을 넣는다.
- 문제 전체를 되풀이하거나 모든 문항에 같은 결론 문구를 붙이는 해설은 허용하지 않는다.
- 모든 활성 문항은 `core-items.json`의 핵심 학습 항목 하나에 연결한다. 핵심 항목마다 적어도 한 문항을 둔다.
- 공식 기출 연결은 문항을 직접 대조해 정확히 확인하고 `official-link-allowlist.json`에 근거를 기록한 `sourceQuestionIds`만 허용한다. 키워드가 겹친다는 이유로 자동 연결하지 않는다.

## 검증 자료와 범위

검수의 1차 범위는 저장소에 보존된 원본 족보 이미지와 원삼국 배치표, 족보 전사 자료이다. 저장소의 제57~79회 한국사능력검정시험 심화 원문·정답·해설 목록은 특정 기출 문항을 직접 확인할 때만 사용한다. 연도, 인물-저술, 제도 시행 주체처럼 오답 가능성이 큰 항목은 다음 공공 역사 자료를 우선해 교차 확인한다.

- 국사편찬위원회 [우리역사넷](https://contents.history.go.kr/)
- 국사편찬위원회 [한국사데이터베이스](https://db.history.go.kr/)
- 한국학중앙연구원 [한국민족문화대백과사전](https://encykorea.aks.ac.kr/)
- 국가기록원 [국가기록포털](https://www.archives.go.kr/)
- 국사편찬위원회 [한국사능력검정시험](https://www.historyexam.go.kr/)

## 재생성 및 검사

```text
npm run build:ox
npm run check:ox
node tests/ox-quiz-test.cjs
node tests/ox-quiz-mobile-test.cjs
```

검사기는 활성 ID와 폐기 ID의 충돌·재사용, 핵심 항목 매핑, 명시적 기출 연결, 진술형 문장, 2~4문장 해설, X 문항의 오류 지적, 기계적 금지 문구, 중복 문항·해설, 문제에 없던 추가 학습 정보의 존재를 확인한다. 검수 원고와 생성 결과가 어긋나면 빌드가 실패한다.
