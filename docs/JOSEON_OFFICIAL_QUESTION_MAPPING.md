# 조선편 실제 기출 → 스토리 매핑

기준 원본은 국사편찬위원회 한국사능력검정시험 제73~79회 심화 문제지와 정답표이다. 범위는 조선 건국부터 신미양요까지(1392~1871)이며, 강화도 조약 이후 문항은 다음 시대 범위라 제외한다. 아래 65문항은 모두 원본 문제 이미지와 정답표를 대조했으며, 앱에서는 `officialQuestionId = joseon-official-{회차}-advanced-{번호}`를 유일 키로 사용한다.

## 설계 원칙

- 순서: 실제 기출 → 핵심 개념 → 역사적 사건 → 스토리 경험 → 동일 기출 회수.
- 한 장면은 한 핵심 기억에 집중하고, 연관 문항은 1~3개 묶음으로 배치한다.
- 원본 기출은 `실제 한능검 기출`, 자체 제작 보충 문항은 `심화 연습 · 자체 제작`으로 분리한다.
- 관련 장면과 원본 문제는 같은 `officialQuestionId`, `relatedSceneId`, `sourceQuestionImage`로 기출 모음과 오답노트에서 재사용한다.
- CH.00은 세계관 진입 장이라 문제를 배치하지 않는다.

## 챕터별 회수 결과

- 실제 기출 포함: CH.01, CH.03~04, CH.07~22.
- 직접 대응하는 제73~79회 문항이 없는 CH.02(왕자의 난), CH.05(훈민정음), CH.06(4군 6진)는 사실관계 보충용 `심화 연습`만 배치한다.
- 실제 기출 65문항은 이야기 안 문제 세트, 시대별 기출 모음, 전체 기출문제 화면, 오답노트에서 동일 ID로 공유한다.
- 조선 기출문제 메인은 CH.00~CH.22 전체 완료 전 `LOCKED`, 전부 완료 후 `UNLOCKED`가 된다.
