## 재생 순서와 공통 UI

8개 구간과 83개 장면, 선택 장면 36개와 선택문 108개를 설치한다. 모든 분기를 합한 발화는 1,369개이다. 본문 937개, 선택한 주인공 발화 108개, 개별 반응 219개, 공통 합류 대사 105개로 구성한다. A/B/C 중 하나를 각 장면에서 고른 실제 경로는 각각 1,151개 발화를 재생한다.

한 장면은 본문을 모두 읽고, 선택이 있다면 선택 버튼의 문장을 주인공 발화로 한 번 보여 준 뒤 해당 반응과 공통 대사로 이어진다. 공통 대사 완료 지점의 기출을 풀고 다음 장면으로 진행한다. 선택에는 임의의 체력·지식·재산·관계 보상을 추가하지 않는다. 단 27세, 라온 19세, 현대 남성 주인공 24세를 유지한다.

기존 공통 game(), dialogueBubble(), choiceButtons(), characterStage()의 구조와 스타일을 재사용한다. 일반 진행에서 최근 3개, 선택 화면에서 최근 2개의 대사를 보여 주며, 기존 버튼·오른쪽 주인공 말풍선·왼쪽 등장인물 말풍선·캐릭터 배치를 유지한다. PC의 게임 폭은 기존 430px이다. proto-revision.css는 원문의 줄바꿈과 긴 선택문 높이만 보완하며, 캐릭터 위치나 게임 폭을 바꾸는 규칙을 추가하지 않는다. 신규 기록책과 기출 화면에만 별도의 내용 스타일을 사용한다.

## 학습과 기출

새 기록책의 공통 lineId 읽기 기록으로만 31개 학습 항목을 연다. 장면 방문, 옛 완료 기록, 선택 분기, 이전 문제 풀이의 존재만으로는 새 공통 학습을 완료하지 않는다. 총 공통 발화 1,042개를 각각 추적하고, 해당 장면의 본문과 합류 대사를 모두 읽어야 readSceneIds에 기록한다.

23개 기출은 원고에 지정된 11개 큐로 연결한다. 각 큐의 afterLineId와 각 문항의 requiresReadSceneIds를 검증한다. 기본 문제의 보기는 4개, 심화 문제의 보기는 5개이며 원본 문항 이미지를 전체 표시하고 확대할 수 있다. 이미지 23개의 SHA-256과 정답 인덱스를 승인 원본 및 기존 공식 카탈로그에 대조한다. 정답은 이미 검증된 0부터 시작하는 인덱스를 그대로 사용한다.

문제를 연 것, 임시로 답을 고른 것, 실제 답을 제출한 것을 구분한다. 정수 범위의 실제 답변만 완료된 officialQuestionId에 포함하며 오답도 제출된 풀이로 인정한다. 이미 제출한 기출은 의무 큐에서 반복하지 않고 기록책에서 명시적으로 다시 풀 수 있다. 선택적 복습은 현재 본편의 커서·분기·기출 큐를 바꾸지 않는다.

진행 중 해설은 승인 원본의 playExplanation을 사용한다. 삼한 공통 학습인 proto_ch06_s7을 마친 뒤 여러 나라 비교 해설을 열며, 다른 시대의 보기까지 포함하는 전체 해설은 독립 학습을 명시적으로 선택할 때 연다. 옛 문제 객체는 보존한 채 공통 오답·기억 UI에 넘기는 표시용 해설을 제한한다.

## 저장과 마이그레이션

원삼국의 현재 저장 버전은 3이며 다음 이름을 사용한다.

| 구분 | 이름 |
| --- | --- |
| 시대 진행 | proto-kingdoms-v3 |
| 독립 복구 저장 | lived-history-proto-kingdoms-v3 |
| 이전/알 수 없는 저장 보관 | lived-history-proto-kingdoms-archives-v3 |
| 원고 버전 | proto-revision-83-v1 |

run 및 mainRun의 본문·선택·발화·반응·합류·기출 단계, 정확한 커서, 선택문, 대기 반응, 기출 큐와 임시/제출 답을 검사한다. 구조상 맞는 커서라도 앞선 공통 lineId의 읽기 증명이 없으면 새 진행으로 신뢰하지 않는다.

기존 원삼국의 run/mainRun, chapterRecords의 finalRun/firstRun/latestRun, chapterRuns, 시대별 resume.run/resume.mainRun과 이전 기록책은 원래 payload로 보관한다. 새 contentVersion의 완료 상태로 자동 승격하지 않는다. 옛 questionRecords와 누적 풀이 기록, 다른 시대의 진행과 저장 키는 보존한다. 새 기록책이 유효하고 현재 커서만 손상된 경우 유효한 공통 학습·풀이·완료 기록은 보존하고 해당 커서만 안전한 시작점으로 복구한다.

독립 저장은 공통 저장이 없거나 잘못된 경우 복구할 수 있다. 알 수 없는 JSON과 스키마는 새 값으로 교체하기 전에 원본 문자열 또는 객체를 보관한다. 잘못된 보관 목록 자체도 버리지 않고 별도 항목으로 보존한다. 다른 시대의 mainRun이 있는 원삼국 재플레이는 해당 mainRun을 유지하며 완료 후 또는 메뉴에서 이어하기를 선택할 때 원래 진행을 복원한다.
