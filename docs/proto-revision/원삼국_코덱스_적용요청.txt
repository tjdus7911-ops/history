# 작업 요청: 원삼국 개정 대본·족보·기출 배치 적용

저장소: https://github.com/tjdus7911-ops/history

첨부 `눈떠보니원삼국_개정대본_83씬.md`, `눈떠보니원삼국_83씬_족보_기출배치표.xlsx`, `눈떠보니원삼국_개정게임데이터.json`을 끝까지 읽고 기존 원삼국에 적용해줘. 이 요청은 원삼국에 관한 것이며 삼국편의 확정 23챕터 작업과 구분해줘. 실제 현재 저장소와 지침을 확인한 뒤 기존 변경과 다른 시대의 진행을 보존해줘.

## 적용 원본
기존 실제 적용본의 본편 6챕터, 프롤로그·결말을 포함한 8구간 83씬이다. 미연결 5챕터 재구축 초안으로 바꾸지 마. 기존 씬 ID·제목·순서와 36개 선택 위치를 유지한다. 작성 발화는 1,369개, 선택지는 A/B/C 108개이며 세 분기를 합친 원고 수량이다.

## 재생
본선 마지막 발화 → A/B/C 실제 대사 선택 → 고른 문장을 주인공이 한 번 발화 → 그 분기의 reply → join → 지정 기출 큐 → 다음 씬. spokenLine과 label을 따로 두 번 읽지 마. 선택에 정답·오답·지식 점수·새 호감도 수치를 붙이지 마. 어느 선택에서도 공통 학습과 다음 씬에 도달하게 해줘. 긴 대사는 줄이지 말고 모바일 UI에서 읽게 해줘.

## 역사와 연출
24세 현대 남성 주인공, 단27·라온19와 기존 인물·큰 줄기를 유지한다. 원삼국 주인공을 삼국편 서아로 바꾸지 않는다. 매듭은 단이 라온에게 만들어 준 물건이며 라온도 그 방식으로 묶는다. 편지의 진실은 CH06 S12에서 고백한다. 라온은 철을 배우고 싶어 떠난 사람이며 납치·사망 설정을 추가하지 마.
주몽은 이야기꾼의 건국 전승으로 표시하고 직접 만나는 장면으로 바꾸지 마. 창작 여행은220년 늦가을~221년 늦봄이다. 겨울 영고 체험과10월 동맹·무천의 설명을 구분한다. 고구려1책12법의 후대 사료 차이, 삼한 두레의 후대 조직과 구별, 천군=사람/소도=신성 구역의 구분을 보존한다. 사진의 암기 원문 `부영(이와) 고동(어는) 동무(다)`을 괄호까지 유지한다.
staging·memoryHook·recall·learning·source·정답은 제작 정보이며 그대로 NPC 대사로 읽지 않는다. 원고에 명시한 주인공 속마음·학습 주석은 그 표시를 유지한다.

## 기출
선정된 실제23문항을 officialQuestionId로 구분한다.11지점에서 최대3문항씩, 해당 공통부의 지정 마지막 lineId까지 읽은 뒤 한 문제씩 연다. 프롤로그, CH06 S08~14 재회, CH07 S05~08 작별에는 강제 기출을 넣지 않는다.
기본4지·심화5지를 유지하고 원문 자료·보기 순서·정답을 보존한다. answerNumber1은1기반이고 answerIndex0는0기반이다. 변환은 한 번만 한다. 이미지와 공식 원문·정답 근거는 JSON의 source 및 해시를 대조한다. 71회 심화2는 잘린 후보로 제외되어 있으므로 검증 없이 추가하지 마.
원문에는 아직 배우지 않은 나라·본편 밖 보기가 남는다. 정답을 판단할 필수 공통 학습은 먼저 읽게 하고, 현재 playExplanation만 먼저 표시한다. 원삼국 전체 비교 해설은 CH06 S07 이후, 본편 범위 밖 상세 해설은 명시적으로 여는 독립 학습에서 다룬다. 문항을 열기만 한 상태와 답변 완료를 구분하고, 이미 푼 공식문항을 필수 문제로 다시 강제하지 마. 선택 복습은 별도로 허용한다.
