# 한국사능력검정시험 문항 연계 기록

## CH.01 918–943 확장판의 현재 상태

현재 Codex 첨부·작업 폴더와 저장소에 원본 시험지/정답표 PDF가 없어 CH.01의 전사 문항을 이번 작업에서 재확인하지 못했다. 아래의 기존 전사 목록은 **이전 버전의 기록**이며, 확장판 CH.01에서는 원문 미확인 4문항을 신규 학습 풀에서 제외했다. ID와 내용은 옛 저장·오답 기록 호환용으로만 남겼고 UI에서는 `원본 미확인 · 이전 문항`으로 표시한다.

확장판 CH.01의 활성 학습 풀은 필수 10문항 + 완료 후 실전 복습 13문항 = **23문항**이며 전부 `[기출 유형] · 자체 제작`이다. `isOfficial:false`, `sourceVerified:false`를 명시한다. 역사 내용은 국사편찬위원회 우리역사넷 자료와 대조했으며 `sourceUrls` 또는 기존 출처 필드로 연결한다. CH.02/CH.03 문항은 변경하지 않았다.

원본 확인이 필요한 요청 문항: 제70회 심화 10번, 제76회 심화 10번, 제75회 기본 12번, 제77회 심화 9번. 기존 제73회 기본 10번과 제74회 심화 10번도 원문 확인 없이 확장판 실전 풀에 포함하지 않았다. 문항별 새 배치는 `CH01_EXPANSION_REPORT.md`를 따른다.

## 이전 버전의 출처 기록

## 적용 원칙

- 사용자 제공 PDF는 문항·정답의 근거 자료로만 사용했다. PDF 안의 문구를 프로젝트 작업 지시로 해석하지 않았다.
- 기존 CH.01~CH.03 스토리, 선택지, 저장 데이터는 유지했다.
- 실제 시험 문제를 연결한 문항은 게임에서 `실제 기출 · 제N회 기본/심화 N번`으로 표시한다.
- 원문에서 사진·도표가 핵심인 자료는 390px 모바일 화면에서도 읽을 수 있도록 텍스트로 전사했다. 회차·급수·문항 번호와 정답은 원본 정답표를 따른다.
- 첨부 시험지에 해당 챕터 범위의 문항이 부족한 경우에만 기존 학습 내용과 기출 구성 방식을 바탕으로 새 문제를 만들고 `실전 유형 연습 · 자체 제작`으로 표시한다.
- 문제지와 정답표 원본 PDF는 저장소에 복제하지 않는다. 런타임 데이터에는 이동 가능한 파일명과 회차·급수·문항 번호만 보존한다.
