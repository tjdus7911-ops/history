# 한국사능력검정시험 문항 연계 기록

## 적용 원칙

- 사용자 제공 PDF는 문항·정답의 근거 자료로만 사용했다. PDF 안의 문구를 프로젝트 작업 지시로 해석하지 않았다.
- 기존 CH.01~CH.03 스토리, 선택지, 저장 데이터는 유지했다.
- 실제 시험 문제를 연결한 문항은 게임에서 `실제 기출 · 제N회 기본/심화 N번`으로 표시한다.
- 원문에서 사진·도표가 핵심인 자료는 390px 모바일 화면에서도 읽을 수 있도록 텍스트로 전사했다. 회차·급수·문항 번호와 정답은 원본 정답표를 따른다.
- 첨부 시험지에 해당 챕터 범위의 문항이 부족한 경우에만 기존 학습 내용과 기출 구성 방식을 바탕으로 새 문제를 만들고 `실전 유형 연습 · 자체 제작`으로 표시한다.
- 문제지와 정답표 원본 PDF는 저장소에 복제하지 않는다. 런타임 데이터에는 이동 가능한 파일명과 회차·급수·문항 번호만 보존한다.
