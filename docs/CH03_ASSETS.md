# CH.03 신규 에셋 맵

CH.03의 모든 이미지는 기존 프로젝트 이미지와 `DOYUN_CANONICAL`, `HYUNWOO_CANONICAL`, `PLAYER_CANONICAL`을 로컬 참조 이미지로 넣어 생성했습니다. 세로 2:3, 하단 대화 UI 여백, 잉크·수채 질감, 다크 네이비·아이보리·흙빛 팔레트를 공통 규칙으로 사용했습니다. 광택 3D, 사진풍, 네온, 현대 물건, 과장된 판타지 장식은 제외했습니다.

## 캐릭터 생성 기준

- 도윤: `doyun_956_neutral.png`를 기준으로 얼굴 골격, 눈매, 코, 상투를 잠그고 약 90세까지 자연스럽게 노화했습니다. 거의 백발, 긴 백수염, 깊은 주름, 굽은 어깨, 지팡이, 나이 든 손, 성공한 상단주의 절제된 남색 복식입니다.
- 현우: `hyunwoo_neutral.png`를 기준으로 얼굴과 학자 인상을 유지하고 47세 전후로 노화했습니다. 관자놀이의 옅은 새치와 성숙한 얼굴선, 연녹색 관료·학자 복식, 책을 공통으로 유지합니다.
- 주인공: 신규 포트레이트를 만들지 않고 기존 `player_goryeo_*` 세트를 그대로 사용합니다. 마지막 장면 합성에서도 얼굴·머리·23세 외형·평민복을 바꾸지 않았습니다.

생성 방식: Codex 내장 ImageGen. 캐릭터 포트레이트는 투명 PNG, 장면 일러스트는 불투명 PNG로 생성했습니다.
