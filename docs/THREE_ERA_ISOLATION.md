# 삼국시대편 데이터 경계

새 30챕터 삼국편은 개발 미리보기에서만 설치한다. 공개 `index.html`과 기존 원삼국·고려·조선 파일은 수정하지 않는다. 정식 적용은 콘텐츠와 실제 화면 검증을 마친 이후 별도로 진행한다.

| 구분 | 새 삼국시대편 |
| --- | --- |
| 메인 시대 항목 | `three-kingdoms` (원삼국 `proto-kingdoms`와 별도) |
| 주인공 | `three_v2_seoa` / 서아 / 여성 |
| 챕터 | `three-v2-ch01` ~ `three-v2-ch30` |
| 씬 | `three_v2_ch01_s1` ~ `three_v2_ch30_s3` |
| NPC | 각 씬의 `three_v2_` 이름 공간 |
| 기출 배치 | 씬 ID와 공식 문제 ID를 결합한 별도 문항 ID |
| 배경·캐릭터 파일 | `assets/ancient/three-v2/` |
| 시대별 진행 키 | `three-kingdoms-v2` |
| 독립 복구 저장 키 | `lived-history-three-kingdoms-v2` |
| 미리보기 전체 저장 키 | `lived-history-three-development-v2` |

원삼국의 `proto-kingdoms` 진행 키와 기존 공개 전체 저장 키 `lived-history-v1`은 바꾸지 않는다. 삼국편의 독립 복구 레코드에는 삼국편 챕터·문항 기록만 저장한다. 복구 시에도 소속 챕터·씬·콘텐츠 버전을 검사하고 다른 시대 기록을 병합하지 않는다. 이전 삼국편의 진행도를 새 대본으로 자동 전환하지 않는다.

새 삼국편에 한해서 공통 초기 상태의 고려 인물과 복식 정보를 정리한다. 원삼국 남자 주인공·단·라온, 고려와 조선의 데이터는 그대로 둔다. 재사용한 여성 주인공 표정 11장과 표지 1장은 새 경로에 동일 바이트로 복사하고 원본은 보존한다. 이 복사본을 신규 창작 일러스트 수에 포함하지 않는다.

시대 레지스트리의 전용 진행 키는 UI가 저장 데이터를 읽기 전에 설치한다. 새 삼국편의 챕터 완료 결과도 이 키에 기록하며 이전 삼국편 진행 레코드는 보존한다. 고려 챕터를 완료한 저장 파일에서 공통 마이그레이션이 삼국 주인공에게 고려 복식을 주입하던 경우는 새 삼국편 실행 상태를 보존하는 로딩 어댑터로 차단한다. 기존 시대에는 원래 마이그레이션이 그대로 적용된다.

자동 검사는 네 시대에 실제 `resumeEra` 함수로 진입하고, 다른 능력치·플레이 위치·문제 풀이 기록을 저장한 뒤 역순으로 복귀해 비교한다. 새 삼국편의 챕터 선행 조건이 다른 시대를 요구하지 않는지, 독립 복구가 다른 시대의 기록을 보존하는지도 확인한다. 원본 캐릭터·초상·배경 객체는 공개 엔트리 실행 결과와 대조한다.

이 검사는 VM에서의 데이터·HTML·동작 검사이며 PC·모바일 브라우저 실기 검사를 대체하지 않는다. 실제 화면 검증은 컴퓨터 사용 도구의 초기화 오류로 아직 미완료다.
