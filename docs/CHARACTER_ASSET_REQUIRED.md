# CH.01 캐릭터 포트레이트 제작 목록

현재 모든 포트레이트는 unrelated 이미지 대신 `ASSET_REQUIRED` 실루엣 플레이스홀더로 표시됩니다. 실제 제작 시 **투명 배경 PNG/WebP, 3:4 비율, 최소 900×1200px, 얼굴부터 허리 위까지 보이는 반신 구도**를 사용합니다. 모바일 말풍선 옆 60×76px까지 축소되므로 눈·눈썹·입의 표정이 작은 크기에서도 구분되어야 합니다.

## 캐릭터 디자인 고정 기준

- **주인공(player)**: 2026년 한국의 20대 초반 학습자. 타임슬립 직후 현대적인 짙은 남색 후드형 상의 위에 현지에서 빌린 거친 베이지색 겉옷을 걸친 혼합 복식. 검은 머리, 단정하지만 잠에서 막 깨어 약간 흐트러진 앞머리. 모든 표정에서 얼굴형·머리·의상·가방끈을 동일하게 유지합니다.
- **도윤(doyun)**: 918년 송악을 오가는 20대 후반 젊은 상인. 햇볕에 살짝 그을린 얼굴, 짙은 갈색 머리를 낮게 묶고, 갈색·먹색의 실용적인 포와 천 허리띠, 작은 장부 주머니를 착용합니다. 왕족·무사처럼 화려하게 표현하지 않습니다.
- **낯선 청년(stranger)**: 송악 길목 민가의 20대 후반 주민. 수수한 회갈색 포, 헝클어지지 않은 상투 전 단계의 묶은 머리, 선한 눈매. 도윤과 얼굴형·의상 색을 명확히 구분합니다.
- **주민·노인·아이·상인**: 10세기 생활인으로서 삼베·모시 질감의 소박한 옷을 사용합니다. 조선 후기 갓·도포, 현대 단추·지퍼, 판타지 갑옷을 사용하지 않습니다.

## 일관성 제작 규칙

1. 먼저 `player_neutral`, `doyun_neutral`, `stranger_neutral`, `merchant_neutral`을 캐릭터 기준 시트로 확정합니다.
2. 동일 인물의 표정 변형은 기준 시트의 얼굴형, 눈·코·입 위치, 머리 길이, 의상 봉제선과 색을 고정하고 표정과 미세 포즈만 변경합니다.
3. 모든 NPC는 왼쪽 배치를 전제로 화면 오른쪽을 바라보고, 주인공은 오른쪽 배치를 전제로 화면 왼쪽을 바라봅니다.
4. 배경이 투과되는 반신 포트레이트로 제작하며, 말풍선에 닿는 바깥쪽 어깨가 잘리지 않도록 8% 이상의 투명 여백을 둡니다.
