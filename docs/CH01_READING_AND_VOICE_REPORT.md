## 검증 한계

실제 브라우저 모바일 플레이 및 시각 검수는 수행하지 못했다. 내장 Browser 연결은 kernel assets 경로 오류로 실패했고, 저장소 Playwright 테스트의 Chrome 실행은 `spawn EPERM`으로 실패했다. Chrome 읽기 권한을 추가한 뒤에도 같은 오류였으며 별도 프로세스 실행은 샌드박스 승인 정책에서 거부됐다. 따라서 자동 UI 흐름 검증과 이미지 참조 검증은 통과했지만 실제 모바일 레이아웃·이미지 구도 검증은 미완료이다. 모바일 테스트의 변경된 문장/진행 위치에 대한 기대값은 새 흐름에 맞게 수정했다.
