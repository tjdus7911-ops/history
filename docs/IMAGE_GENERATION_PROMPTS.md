# CH.01 이미지 생성 최종 프롬프트 기록

이 문서는 실제 게임에 연결한 생성 이미지의 재현·확장용 프롬프트 기록입니다. 모든 결과물은 이미지 내부에 글자·로고·워터마크를 넣지 않고, 텍스트와 HUD는 웹 UI에서 렌더링합니다.

## 공통 장면 스타일

```text
세로형 2:3, 1024×1536, 프리미엄 모바일 비주얼노벨의 반실사 2D 한국 웹툰 일러스트. 영화적인 빛, 선명한 인물 실루엣, 섬세한 머리카락과 옷감, 짙은 네이비·아이보리·따뜻한 금색 팔레트. 하단 대화 UI와 상단 HUD를 위한 읽기 쉬운 여백을 확보한다. 918년 고려 전기의 초가, 흙길, 목제 수레, 삼베·모시 복식을 사용한다. 조선 후기 갓·도포, 판타지 갑옷, 현대 간판·전선·플라스틱을 금지한다. 이미지 안에 텍스트, 말풍선, 로고, 워터마크를 넣지 않는다.
```

## 주인공 기준 프롬프트

```text
같은 주인공을 유지한다: 2026년 한국의 20대 초반 남성, 검고 약간 흐트러진 짧은 머리, 선명한 회갈색 눈, 갸름하지만 건강한 얼굴. 짙은 차콜 재킷 안에 연회색 후드, 검은 티셔츠. 얼굴부터 허리 아래까지 보이는 투명 배경 PNG, 오른쪽 배치용으로 화면 왼쪽을 보는 3/4 구도. 가방, 크로스백, 배낭, 가방끈, 시대 의상, 장신구 없음. 기준 얼굴·머리·재킷·후드 디자인을 모든 표정에서 동일하게 고정한다.
```

표정 변형: `neutral` 차분한 기본, `smile` 안도하는 작은 미소, `surprised` 눈을 크게 뜬 놀람, `embarrassed` 난처해 시선을 피함, `worried` 불안한 눈빛, `thinking` 턱 가까이 손을 둔 분석, `serious` 단호한 결심, `angry` 불의를 보고 화남, `sad` 고개를 숙인 슬픔.

## 도윤 기준 프롬프트

```text
같은 도윤을 유지한다: 918년 송악을 오가는 20대 후반 고려 상인, 햇볕에 살짝 그을린 얼굴, 짙은 머리를 단정한 상투로 묶음, 남색·회갈색 삼베 포와 천 허리띠. 왕족·장군처럼 화려하지 않은 실용적 복식. 얼굴부터 허리 아래까지 보이는 투명 배경 PNG, 왼쪽 배치용으로 화면 오른쪽을 보는 3/4 구도. 기준 얼굴·머리·의상 디자인을 모든 표정에서 동일하게 고정한다.
```

표정 변형: `neutral` 침착하게 상대를 살핌, `smile` 믿음직한 작은 미소, `surprised` 예상 밖의 대답에 놀람, `suspicious` 의심스레 눈을 좁힘, `serious` 현실적인 조언, `worried` 혼란을 걱정함.

## 후속 의상 에셋

현재 코드의 플레이어 의상 키는 `modern`이며 `player_modern_*` 파일을 사용합니다. 고려 생활에 적응한 뒤에는 같은 얼굴·머리를 유지한 `player_goryeo_neutral`, `player_goryeo_smile`, `player_goryeo_surprised`, `player_goryeo_worried`, `player_goryeo_thinking`, `player_goryeo_serious`, `player_goryeo_embarrassed`, `player_goryeo_angry`, `player_goryeo_sad`를 제작하고 `CHARACTERS.player.portraits.goryeo`에 연결합니다.
