# CH.03 캐릭터 슬롯 수정

기준 main: `381dcbd4f6a5bab3e8fcbc66845ded2722f573d9`.

## 원인과 적용 방식

CH.01 첫 만남의 `stagePortrait`, `resolvedPortraitId`, 공통 크기/앵커 프로필, `.stage-left`/`.stage-right`, `.active`/`.listening`을 재사용했다. 기존 일반 렌더러는 최근 2–3개 대사에서만 등장 인물을 고르므로 듣는 사람이 사라졌고, CH.03 일부 배경의 `embeddedCharacters: true`가 초상 전체를 차단했다. 일부 NPC는 `ambient`/`show: false`, 현우는 오른쪽 위치여서 주인공과 같은 슬롯에 놓였다.

- CH.03 장면의 `characterSlots: 'player-partner'`로 공통 두 슬롯 연출을 사용한다.
- PLAYER SLOT은 오른쪽이며 주인공이 유지된다. 상대방의 첫 발화에서도 기본 주인공 초상을 표시한다.
- PARTNER SLOT은 왼쪽이며 지금까지 진행한 전체 대사의 마지막 NPC를 유지한다. 주인공이 답해도 상대는 사라지지 않는다.
- 새 NPC가 말하면 왼쪽만 교체한다. 도윤의 발화가 다시 나오면 왼쪽도 도윤으로 돌아온다. 현우·길상·관리·귀족 등도 같은 왼쪽 기준이다.
- 선택 결과가 주인공으로 시작하면 그 결과의 첫 NPC를 대화 상대로 표시한다. 결과에 NPC가 없다면 선택 이전 장면의 상대를 이어받는다.
- 화면에 존재하는 두 사람과 현재 발화자를 별도로 계산한다. 발화자는 기존 `active` 스타일(불투명도 1), 상대는 `listening` 스타일로 어둡게 표시한다.
- 배경은 그대로 두고, 해당 대화에서는 그 배경의 포괄적인 초상 숨김 플래그에 의해 두 슬롯이 차단되지 않게 했다. 배경 속 군중/사건 그림을 별도 대화 슬롯으로 세지 않는다.
- 순수 내레이션·속마음·검은 전환 화면은 기존 연출을 유지한다. 다른 챕터는 새 모드를 선언하지 않아 기존 표시 방식을 유지한다.
- 대사/선택/문제/경로/배경/캐릭터 이미지 파일은 변경하지 않았다. 저장 필드를 추가하지 않았으며 재진입 시 대사 커서로 슬롯을 복원한다.

## 검증

- `npm test`: 통과. CH.01–12 전체 회귀 및 CH.03 처음부터 끝까지 UI 이벤트 진행, 선택 분기, 3개 본편 문제, 5개 복습 문제, CH.04 연결, 재플레이/저장 검증.
- `tests/ch03-character-slots-test.cjs`: 36개 장면, 모든 선택 결과, 162개 발화 검사(재진입 검사 포함). 최대/정확히 2개 슬롯, 오른쪽 주인공, 왼쪽 상대, NPC 교체, 활성/비활성 강조, 이미지 참조, 재진입을 확인했다.
- `tests/fixtures/ch03-stage-protected.json`: CH.03 모든 장면의 대사/선택/문제/경로 등 원본 해시 보존을 검사한다. 변경은 `characterSlots` 메타데이터뿐이다. 관련 기존 이미지 38개도 원본 해시와 일치한다.
- `npm run build`: 통과. 필수 24개 파일, 준비된 이미지 321개, PWA 구조/문법 확인.
- `git diff --check`: 통과.
- 모바일 테스트 `tests/ch03-character-mobile-test.cjs`를 추가했다. 375/390/430px의 CH.03 전체 진행, 슬롯/강조, 이미지 decode, 가로 overflow, CH.04 해금을 검사하도록 작성했다.

## 실제 브라우저 검수 한계

내장 Browser 연결은 kernel assets 경로 오류로 실패했고, 기존 전체 모바일 테스트와 새 CH.03 모바일 테스트 모두 Chrome 실행이 `spawn EPERM`으로 거부되어 수행하지 못했다. 실제 모바일 시각 검수, 이미지 구도 및 새 브라우저 테스트 실행 결과는 미확인이다. 자동 UI 이벤트/렌더 HTML 검증과 이미지 파일 검증 결과와 구별해야 한다.

Chrome 실행이 허용된 환경에서 재실행:

```powershell
$env:BROWSER_CHANNEL='chrome'
node tests/ch03-character-mobile-test.cjs
```
