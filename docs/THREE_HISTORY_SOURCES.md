# 삼국편 역사 사실 검토 근거

다음은 초안 검토에 사용한 국사편찬위원회 우리역사넷 자료다. 역사적 사실과 서아·주민의 허구 사건은 구분한다. 이 목록은 전체 대본의 고증 완료를 의미하지 않는다.

- [진대법 사료](https://contents.history.go.kr/mobile/hm/view.do?levelId=hm_019_0010): 194년 10월 제정, 봄 3~7월 관곡 대여, 겨울 10월 상환. CH.01 첫 만남은 허구의 194년 봄으로 표시하고, 제정은 194년 10월, 시행 뒤 상환 장면은 195년 가을로 구분했다.
- [고국천왕](https://contents.history.go.kr/mobile/kc/view.do?code=kc_age_10&levelId=kc_n100320): 194년 흉년과 구휼 관련 맥락. 허구의 첫 만남을 실제 왕의 특정 행차 기록처럼 제시하지 않는다.
- [원종과 애노의 봉기](https://contents.history.go.kr/front/hm/view.do?levelId=hm_038_0020): 889년 봉기. 공식 61회 8번의 시간 범위와 대조.
- [외사정](https://contents.history.go.kr/front/tg/view.do?levelId=tg_001_0770&treeId=0103): 문무왕 때 673년 설치. 공식 61회 10번 오답 해설 근거.
- [안승](https://contents.history.go.kr/mobile/kc/view.do?code=kc_age_10&levelId=kc_n101270): 674년 보덕국왕 책봉. 공식 61회 7번 시간 범위와 대조.
- [장보고 관련 사료 비교](https://contents.history.go.kr/front/km/view.do?levelId=km_030_0030_0030): 사망 시점에 관해 삼국사기 846년 기록과 일본 측 841년 기록이 다르다. CH.24에서는 특정 날짜의 직접 목격을 단정하지 않고 기록의 불일치를 드러낸다.

기출의 원문·정답표 해시, 회차·문항번호, 육안 대조 여부와 5개 선지 해설은 `THREE_OFFICIAL_REVIEW_61.json`에 기록한다. 아직 배치하지 않은 문항을 검증 완료 개수에 포함하지 않는다.
