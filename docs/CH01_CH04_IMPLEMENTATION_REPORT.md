### CH.01 · 새로운 나라 (918–930)

- 2026 프롤로그, 타임슬립, 현대 옷, 고려 옷, 도윤과 장사 시작을 유지했다.
- 주민들은 궁예와 왕건을 아는 현지인으로 말하고, 주인공만 상황을 모르는 대화로 고쳤다.
- 927년 부상 상인은 918년의 평범한 거래 상인과 같은 `merchant_01`이다. 공산 전투·경애왕·왕건의 패배·신숭겸의 죽음을 생활 피해로 경험한다.
- 도윤과의 싸움/화해는 문제 없이 유지했다.
- 930년 수레를 나눠 싣는 장사 대사로 927년 실패를 짧게 회수했다.
- “이번에는 우리가 이겼군 / 우리가?” 이후에는 문제가 없다.
- 역사 누락: 공산·고창 전용 실제 기출이 아직 3개 미만이므로 해당 세트는 실행하지 않는다.

### CH.02 · 하나가 된 나라 (935–943)

- 견훤·금산사·신검·고려 귀순, 신라의 마지막과 김부, 936년 일리천을 기존 감정선과 3개 선택 분기 안에서 유지했다.
- 66회 심화 9번은 실제 PDF 확인 결과 궁예가 아니라 견훤 문제이므로 CH.02 견훤 풀로 분류했다.
- 일리천 뒤 76회 심화 10번 → 74회 심화 10번 → 70회 심화 10번을 연속 3문항으로 묶었다.
- 김부·호족·사심관·기인 체험 뒤 67회 기본 10번 → 75회 기본 12번 → 65회 심화 10번을 연속 3문항으로 묶었다.
- 발해계 손님·서경·북진과 전쟁 뒤 민생은 생활 장면으로 유지했고, 기출이 모자란 세트는 대기 상태로 남겼다.
- 943년 첫 만남 장소, 도윤의 노화, 주인공 비노화 복선, 태조의 죽음, 훈요 10조, 도윤상단 이름 장면을 유지했다.

### CH.03 · 왕의 나라 (949–960)

- 길상의 노비안검법 체험과 현우의 과거제 감정선을 유지했다.
- 시험 전날은 야간 실내 배경, 시험 당일은 과거 시험장, 공복 장면은 관청 거리로 유지·검증했다.
- 공복·광덕·준풍·호족/공신 견제까지 경험한 뒤 74회 심화 11번 → 68회 심화 11번 → 78회 심화 11번을 연속 출제한다.
- 정책마다 끼어 있던 자체 제작 문제를 메인 경로에서 모두 퇴역시켰다.
- 마지막 기억 회수와 “광종의 왕권 강화” 결론을 한 장면으로 합쳐 반복을 줄였다.
- 길상·현우·도윤의 말투 차이와 세 사람의 관계 장면은 유지했다.

### CH.04 · 나라의 틀 (982)

- 작은 장사 공간 → 성장한 가게 → 도윤상단의 시각적 성장을 유지했다.
- 상단이 겪은 지방 문제에서 최승로·시무 28조·12목·국자감으로 이어지는 흐름을 유지했다.
- 국자감 체험 뒤 75회 기본 10번 → 68회 심화 9번 → 65회 심화 11번을 연속 출제한다.
- 자체 제작 문제 래퍼 9개를 실제 경로에서 제외했다. 모든 역사 문제는 `ch03_policy_effect` 이전에 끝난다.
- 세 사람의 저녁 농담, 태조→광종→성종 흐름, courtyard, weakening, farewell, death, legacy를 유지했다.
- 도윤 혼자 남는 `ch03_doyun_soliloquy`를 추가했다. “가게 하나면 된다고 생각했는데.” → “참 멀리도 왔군.” → “……나쁘지 않은 장사였소.” 뒤 자연사로 이어진다.

## 4. 문제 시스템

- `QUESTION_POOLS`: 개념·왕·연도·챕터 후보별 검증 기출 목록.
- `QUESTION_SETS`: `afterSceneId`, `resumeStoryId`, `requiredCount`, `verifiedCount`, `missingQuestionCount`, `status`를 명시한다.
- `ready`인 세트만 메인 스토리에서 실행한다. `waiting_for_source`는 스토리를 막지 않는다.
- 한 세트는 1/3 → 2/3 → 3/3으로 끊김 없이 진행한다.
- 마지막 해설 아래 `이번 기억 N / 3 정답`과 `이야기 계속`을 표시한다.
- 문제 선택은 누적 응시 횟수가 적은 검증 기출을 우선한다. 풀이 기록, 오답, 역사 카드는 기존 저장 구조를 그대로 사용한다.
