# 캐릭터 스케일 및 후기 고려 에셋 점검

## 공통 렌더링 규칙

캐릭터 중요도를 장면별 CSS가 아니라 공통 프로필로 관리한다.

| 등급 | 기본 배율 | 용도 |
|---|---:|---|
| `MAIN` | 1.00 | 주인공, 도윤, 반복 동행 인물, 화면에 직접 등장하는 역사 인물 |
| `SUPPORTING` | 0.90 | 이름 없는 거래 상인 등 생활형 조연 |
| `EXTRA` | 0.78 | 필요한 경우에만 쓰는 단역 스탠딩 |

초상별 `scale`, `anchorY`, `zIndex`를 추가로 적용한다. 활성/비활성 강조 배율은 이 기본값 위에서 계산한다. `ageState`와 화면 배율은 분리되어, 나이 든 주요 인물이 자동으로 작아지지 않는다.

## 수정한 조기 챕터

- `doyun_935`: 전신 구도를 1.80배, 바닥 앵커 32%로 보정
- `doyun_943`: 전신 구도를 1.80배, 바닥 앵커 32%로 보정
- 935년 거래 상인 계열: SUPPORTING 등급과 초상별 보정 프로필 유지
- 주인공·도윤·길상·현우: MAIN
- 일반 상인: SUPPORTING

390×844 화면에서 CH.02 935년 도윤과 주인공이 함께 보이는 장면을 캡처해, 얼굴과 상체의 시각적 위계가 주요 인물끼리 비슷한지 확인했다. 데이터 속 PNG 프레임 크기가 아니라 실제 화면 구도 차이를 보정한다.

## 후기 고려 캐릭터 연결

새 반복 창작 인물은 `연`(CH.05–07), `선`(CH.08), `무영`(CH.09), `하림`(CH.10), `아린`(CH.11), `준서`(CH.12)이다. 연은 993년 청년 → 1009년 중년 → 1018년 장년, 하림은 1231년 성인 → 1270년 노년 상태를 사용한다.

직접 등장하는 역사 인물 `서희`, `양규`, `강감찬`, `윤관`, `이자겸`, `묘청`, `김부식`, `최충헌`, `김윤후`, `공민왕`, `신돈`, `최영`, `이성계`, `정몽주`는 모두 `MAIN`이다.

## 재사용한 에셋

- 인물 베이스: `official_01.png`, `soldier_01.png`, `noble_01.png`, `villager_old_01.png`, `villager_male_01.png`, `villager_female_01.png`, `laborer_01.png`, `hyunwoo_*`
- 배경 베이스: 기존 북방 길, 개경 시장, 관청 뜰, 밤 장면, 물가, 산사, 전쟁길, 챕터 완료 일러스트
- 새 래스터 파일은 만들지 않았다. 우선 기존 고려 화풍과 모바일 UI를 유지하는 쪽으로 연결했다.

## 추후 전용 에셋이 필요한 부분

현재는 기능과 역사 흐름을 완성하기 위해 아래 항목에 기존 에셋을 임시 재사용한다. 다음 아트 패스에서 전용 제작이 필요하다.

1. 서희·양규·강감찬·윤관의 서로 구분되는 전용 초상
2. 이자겸·묘청·김부식·최충헌의 12세기 전용 초상
3. 김윤후·공민왕·신돈·최영·이성계·정몽주의 전용 초상
4. 연의 993/1009/1018 동일인 노화 세트와 하림의 1231/1270 동일인 노화 세트
5. 선·무영·아린·준서의 고유 초상
6. 서희 담판, 귀주대첩, 서경, 강화도 천도, 처인성, 팔만대장경 조판, 쌍성총관부 수복, 위화도 회군, 선죽교, 고려 멸망 전용 배경

전용 에셋을 추가할 때도 `characterId → ageState → expression/pose/outfit` 구조를 유지하며 장면 데이터에 경로를 반복하지 않는다.
