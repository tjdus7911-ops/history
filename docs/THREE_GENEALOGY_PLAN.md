# 주요 왕 계보·학습 연결 설계

기준: `55609d66afc269394ad604b47bde18aebf5d0ae3`.

상태: 제작 전 기획 제안. 운영 데이터로 로드하지 않는다. 기존 30챕터·90씬 원본과 모든 서비스 파일을 보존한다.

주요 왕 50명/노드를 설계했다. 모든 왕 전원이 수록된 완전 왕계는 아니다. 직전·직후 왕은 역사상의 실제 계승 순서로 기록하며, 이 표에서 생략한 왕을 건너뛰어 부자 관계로 만들지 않는다. 통일신라는 같은 신라 왕조의 학습 구간이다.

점선은 혈연 미확정, 실선은 확인된 혈연, 별도 화살표는 계승이다. 왕 선택 시 업적·사건·챕터·검증 기출을 열고, 미확정 혈연은 “이설/불명” 배지를 보인다. sourceRefs는 사건·국가 자료이며 혈연의 모든 세부가 같은 출처 한 곳에 있다는 뜻은 아니다. 최종 계보 도식 제작 전 왕별 사료 주석 대조가 필요하다.
