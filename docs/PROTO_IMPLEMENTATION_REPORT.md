## 대사와 선택

첨부 설계의 인용 대사·선택 문구 459개를 해당 씬에 모두 보존했다. `PROTO_CONFIRMED_LINES.json`에 원문 위치와 소스 해시를 기록하고 테스트에서 대조한다. 저장된 대화 항목은 609개이며, 이전 선택을 기억하는 감사 대사 3개를 포함하면 구현된 대화 변형은 612개다.

36개 선택 씬의 108개 버튼마다 즉시 다른 반응을 보여 주고 선택 플래그·관계를 저장한다. CH.06 S11의 선택은 S13 감사 대사에 반영된다. 단과 라온의 사연 및 편지·교역단 추적을 결말까지 연결했다. 퀴즈 뒤 선택 결과, 마지막 퀴즈 뒤 챕터 완료, 오답 뒤 계속 진행도 확인했다.

## 실제 기출

15개 체크포인트에 원본 확인된 서로 다른 기출 23개를 배정했다. 목표 45개 대비 22개가 부족하다. 미확보 문항을 창작하거나 다른 시대 문제로 대체하지 않았다. 기출 0개인 두 체크포인트도 이야기를 정상적으로 진행한다.

회차·수준·번호별 전체 배정과 탈락 사유는 [기출 배정표](PROTO_EXAM_ASSIGNMENT.md)에 있다. 기존 문제 객체·원본 이미지·정답·해설을 보존하고, 새 원삼국 연결 객체만 추가했다. 공통 기출 라이브러리 1,800문항과 오답 기록 연결을 유지했다.

## 화면과 자산

현대 주인공 오른쪽, 현재 대화 상대 왼쪽 배치를 적용했다. NPC끼리 대화하거나 회상할 때 현재 주인공을 숨기며 나레이션에는 초상화를 표시하지 않는다. 단은 27세, 라온은 19세 설정이다.

인물 PNG 9개(새 인물 6명과 단의 미소·슬픔·결심 표정), 코드로 제작한 상징적 배경 SVG 11개를 추가했다. 기존 숲·산성·해안 등의 자산도 사용한다. 배경 SVG는 상징 삽화이며 사진풍 장면은 아니다. 그 밖의 표정은 기본 초상화로 표시한다. 필수 배경은 기존 자산과 새 SVG에 모두 매핑했으며 파일 누락은 없다. 추가 사진풍 배경과 NPC별 표정 확장은 이번 산출물에 포함하지 않았다.

구 버전 원삼국의 진행 중 저장은 현재 챕터 첫 씬으로 옮기되 완료 기록·점수·소지품·기존 응답 기록을 보존한다. 진행 중이던 기존 퀴즈는 마친 뒤 해당 챕터 처음으로 복귀한다. 고려·삼국·조선 데이터와 저장 동작은 회귀 검사에서 보존을 확인했다.

## 검증

- `npm test`: 전체 통과. 기존 고려·삼국·조선 플레이, 기출 라이브러리, 이미지 UI, 정답·해설, PWA 빌드 포함.
- 원삼국 전용 테스트: 세 선택 경로 전체 플레이, 정답·오답, 23문항 중복 없는 배정, 저장된 퀴즈 복원, 구 저장 호환, 459개 원문 항목, 다른 시대 및 기존 문제 객체 불변 확인.
- 실제 브라우저: 모바일 360·390·412px에서 83씬과 원본 기출 이미지 23개 표시, 이미지 디코딩 및 가로 넘침 검사. 선택 즉시 반응과 실제 저장 이어하기 확인.
- 별도 Playwright 모바일 스크립트는 이 실행 환경의 브라우저 프로세스 생성 권한 오류(`spawn EPERM`)로 실행하지 못했다. 위 모바일 검증은 연결된 실제 브라우저로 수행했다.

역사 출처·여행 시간과 지리 설명·기출 이용 조건 확인 결과는 기출 배정표에 함께 기록했다. 상업적 재사용 및 개별 사진의 권리 증빙은 저장소에서 확인하지 못했으므로 권리 확보 완료로 판정하지 않았다.
