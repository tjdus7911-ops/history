71회 문항은 `71회 한국사_문제지(심화).pdf` 3쪽과 `제71회 심화 정답표.pdf` 1쪽을 화면으로 대조했다. 문제·지문·선택지·정답·시험 회차·페이지·원본 파일 이름을 저장했다. 해설과 선택지별 해설은 원문 문항에 맞춰 작성했고, 게임 장면 연결 설명은 해설에 분리했다.

기존 74·68·76·77·78회 문항도 사용자 제공 문제지와 정답표의 실제 페이지를 렌더링해 대조했다. 76회 50번은 12쪽, 77회 14번은 4쪽, 나머지는 3쪽이다. 광종이 오답 선택지에만 등장하는 태조·성종·후대 문제를 CH.03 문제로 오분류하지 않았다. 다른 챕터의 문제 데이터는 수정하지 않았다.

1문항 → 현우의 시험 전날, 2문항 → 귀족 숙청, 마지막 3문항 → 사십 년이 넘는 세월로 각각 기존 이야기에 복귀한다. 기존 정답/오답 기록, 지식 보상, 해설, 오답 노트, 저장 및 복습 흐름을 재사용한다. 마지막 3문항을 앞부분에 중복 출제하지 않는다.

## 캐릭터 표시

CH.03의 `characterPortraitIds`를 주인공·도윤·현우로 제한했다. 조연의 대사·이름은 유지하되 조연 초상은 표시하지 않는다. 원본 배경과 이미지 파일은 수정하거나 삭제하지 않았다.

도윤/현우 대화는 상대 왼쪽, 주인공 오른쪽으로 유지하며 발화자를 강조한다. 조연 발화에는 주인공만 오른쪽에 듣는 상태로 남고 조연 초상은 없다. 화면에 도윤·현우·주인공을 세 명 동시에 표시하지 않는다. 내레이션과 퀴즈에는 대화 캐릭터 레이어가 없다. 표시 필터는 퀴즈 출제나 장면 이동 로직에 관여하지 않는다.
