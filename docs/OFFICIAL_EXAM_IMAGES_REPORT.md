## 변경 및 테스트

공통 dist/official-exam-images.js를 통해 전체 챕터에 출처·원본 이미지·원문 선택지를 연결한다. 기존 문제 ID/텍스트 데이터/정답 인덱스/스토리/분기/저장 기록은 유지했다. 공통 화면에서 실제 기출 표시, lazy loading, 이미지 확대/닫기, 정답 번호/해설/스토리 복귀를 처리한다.

변경: dist/app.js, dialogue.css, exam-data.js, official-exam-images.js, index.html, sw.js; dist/assets/exams/shared/ WebP 13개; package.json; tests/build.cjs; tests/official-image-ui-test.cjs, official-image-mobile-test.cjs, fixtures/official-exam-image-sources.json; 기존 UI/모바일 테스트의 출처 라벨 기대값.

npm test 전체 통과. npm run build 통과. 신규 이미지 13개 crop 시각 검수 및 31개 이미지 SHA-256 검사. 41개 등록 기출의 정답/오답·해설·원문 선택지·확대/닫기·오답 저장 회귀 검사 통과.

390×844 실제 브라우저 검증은 Chrome 실행 spawn EPERM으로 차단되었다. 인앱 브라우저도 커널 자산 생성 오류로 실행 불가했다. 모바일 검증 완료를 주장하지 않는다. 사용자가 모바일 검증을 보류한 상태로 commit/push하는 것을 승인했다. 모바일 실기 검증은 후속 확인이 필요하다.
